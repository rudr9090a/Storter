
# Storter - A music library application

Storter is my small attempt to create a music library application that can be useful for homeservers and self hosted applications, it aims to be lightweight, use minimal resources to provide you with ad-free, uninterrupted and powerful music experience


## Installation

Install and run Storter with python 3.14

```bash
  pip install -r requirements.txt
  python main.py
```
    
## Features

There is a lot to come yet, but here are some projected features, that will be in the program without a doubt before the full release

- Ad free listening - I will never, EVER charge someone money to listen to their own mp3 files lol
- High quality listening - Possibly is maximum quality available from the source, I wouldnt want someone's music streaming quality to be limited by my software
- Playlists
- Liked Songs
- Mashup Playlists - generated by the app
- Possibly a radio feature that will recommend songs based on what youre listening
- BASICALLY, the most popular music streaming apps but with your own server :)
